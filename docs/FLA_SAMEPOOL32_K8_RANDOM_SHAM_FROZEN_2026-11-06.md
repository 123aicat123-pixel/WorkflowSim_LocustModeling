## Locked, outcome-blind selection
- OLD and READY each receive the **same 32 physical mappings** and independently choose greedy marginal predicted 2D HV K=2,4,8 prefixes; predictor-specific planned reference `1.5× max(planned makespan,cost)+1e-6`, tie-break by predicted normalized scalar sum and immutable lexicographic policy name. This reuses `planned_greedy` from the audited 32-source benchmark.
- Random sham: **64** pre-fixed draws per block with NumPy-free Python `random.Random(seed)` (`seed = 5202606 + 1000*block_index + replicate_index`, block order `sorted(DAG×speed)` and replicate indices 0..63); each draw is one random permutation of all **32 policy names sorted lexicographically**. K=2,4,8 selections are nested prefixes of this *same permutation*. The sham does **not** use OLD, READY, or actual HV. Sham statistics descriptive; its 64 permutations do not constitute 64 independent real simulator trials.
- Actual HV per same block: `ref = (1.5× max(all 32 actual makespan)+1e-6, 1.5× max(all 32 actual cost)+1e-6)`; report actual HV and exact K hindsight oracle regret for all OLD/READY selections and sham mean/min/max and quantiles of actual HV, physical selection overlap, full 32-map true Pareto cardinality and K8 saturation.
- Exact hindsight **K=2,4,8** oracle via provably exact 2D nondominated-chain DP: for points sorted by ascending makespan (strictly descending cost), optimal union area of size ≤K is the maximum weight chain using first rectangle `(ref_m-m_i)(ref_c-c_i)` and successive increments `(ref_m-m_j)(c_i-c_j)`; if ND cardinality is ≤K, full true HV saturates. Oracle is **retrospective**, never consulted to select genotypes. Test DP against exhaustive brute force on synthetic and small physical point fixtures before use.
- Main reported per-block estimands: actual READY−OLD K8 HV, compared to same-block sham median, model-dependent physical K8 decision divergence, signed regrets and model errors evaluated on the **identical full 32** actual outcomes. Secondary K2/K4 may reveal rank effects when K8 saturates.
- Preserve ALL positive, zero and negative outcomes; do not select favorite DAG/profile/K/seed after seeing actual labels. No p-values; no claims that random shams prove an algorithm change. Any 32-map source failure rejects its block and entire cohort. `master` and default FLA-v12/NSGA-II remain unchanged.

**Inference boundary:** a same-pool OLD vs READY difference isolates a *fixed-pool ranking/selection* effect under the frozen rule. It cannot say whether the previous FLA full-search loss arose during evolutionary trajectory or post-search filtering, because the predeclared 32-map pool is not an actual optimizer history.
