# Frozen theoretical interval-dominance safety gate on 96 real WorkflowSim mappings — 2026-11-04

## Research purpose and source
Existing 256 true WorkflowSim cached evolutionary pilot [41785343850](https://github.com/123aicat123-pixel/WorkflowSim_LocustModeling/actions/runs/41785343850) did NOT deliver robust FLA HV improvement, and the 1%-near-skyline heuristic spent 377–378 out of 378 READY tokens in almost every case. The next test must establish whether an **uncertainty interval** can ever certify *safe* 2D Pareto pruning using only planned Makespan and Cost estimates. Do not add an ad-hoc gate to live FLA until this basic validity check passes.

Original source frozen: 96 real WorkflowSim placement simulations from [Actions 41695356307](https://github.com/123aicat123-pixel/WorkflowSim_LocustModeling/actions/runs/41695356307), 3 previously researched DAG instances ×2 VM speed regimes ×16 fixed independent-of-optimizer Task→VM genotypes per block. Use existing `fla_algorithm_independent_same_mapping_rank_audit.load` unchanged to check original source SHA, mapping, VM speed, real+predicted Makespan/Cost. No new solver/simulator calls, no fitting, no new seeds, no future labels used to form intervals.

## Exact predeclared intervals and certification
For OLD and READY separately, use static `epsilon ∈ {0.001, 0.01, 0.05, 0.10, 0.25}` (fraction, 0.1%, 1%, 5%, 10%, 25%). For each planned point p = (planned_makespan, planned_cost), define relative two-objective intervals L=(1-epsilon)*p and U=(1+epsilon)*p. A point A is **CERTIFIED DOMINANT** over B only if U_A,m < L_B,m AND U_A,c < L_B,c, a conservative strictly-better-on-BOTH condition; all other pair relations are ABSTAIN/UNCERTAIN, even if point estimates appear to dominate. This may reject many valid Pareto dominance relations and could have zero useful coverage.
- Mathematical guarantee is **conditional**: if ALL real objectives of both candidates lie inside their declared intervals, then such a certified dominance is indeed correct. Epsilon itself is NOT calibrated by this study, and numerical correctness on this cohort does not establish an uncertainty guarantee.
- Evaluate all 120 unordered source pairs × six DAG/speed blocks = **720 pairs/model/epsilon**. Exactly one possible orientation or abstain. Against the real WorkflowSim pair, measure true dominance orientation, certified orientations, false confident certified errors, abstentions, certified precision, true dominance recall, and fraction certified among pairwise comparisons.
- Compute empirical interval **per-point joint objective coverage** and per-objective coverage (6×16 points each model), using actual outcomes strictly AFTER constructing intervals. Report worst absolute relative forecast errors and source-specific failing rows, since a few extreme errors can invalidate safe claims.
- Full-band retained candidates: discard B if ANY other candidate certified dominant over B. Score the *real* normalized HV of the kept subset against the REAL HV of all sixteen originals, using one shared source-real 1.5× reference (3× sensitivity) per DAG/speed group, with source truth used only for evaluation and no virtual simulator replays. Report number kept and possible full16 actual nondominated solutions removed. This is a diagnostic conservative screen; it does NOT guarantee reducing future READY calls since some candidate may need different fidelity calculations to resolve ambiguities.
- Report false certifications and interval coverage failures even when real-HV of retained candidates looks excellent. Choose NO epsilon after reading outcomes; all five levels are sensitivity diagnostics, not tuned candidate methods.
- Do not claim 96 independent experimental units, Q1 research novelty, confidence intervals, distribution-free bounds, a new FLA algorithm, or actual compute-time savings. Only three familiar DAG families, unrealistic source VM mapping extremes, no trusted out-of-family error calibration.
- `master`, original FLA-v12 and NSGA-II defaults, FIFO runtime and prior actual results untouched. This gate is intentionally read-only diagnostic science before a future opt-in interval evaluator is considered.
