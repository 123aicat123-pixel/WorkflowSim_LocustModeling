# Frozen prospective active uniform residual K8 selector test — 2026-11-04

**BEFORE results.** This is a novel research hypothesis and experimental design, not evidence of an improved FLA. No parameters or family labels are adjusted in response to the result. Existing failed PERIODIC/RISK evolutionary policies are excluded because this study isolates post-search K8 candidate selection.

## Hypothesis, controls, and scope
- Test `active-uniform-greedy`: sample T=8 READY points actively among N=32 actual optimizer-visited candidates, estimate the READY/OLD multiplicative residual for every candidate using the nearest measured OLD-space point, then choose K=8 by 2D marginal predicted HV over ONE corrected common objective scale. Includes measured samples themselves on that same scale. No mixed raw OLD and READY scores; no true WorkflowSim labels in acquisition or selection. This 1-nearest-neighbor method is a **heuristic**, not statistical calibration or a guaranteed Pareto certificate.
- Compared to `old-greedy`, `ready-greedy`, and preexisting `staged-greedy` T8 on the SAME N32 ordered original optimizer candidate pool. All 4 variants use the same OLD-only 1.5x max reference and identical greedy HV selection routine. No change to base FLA-v12 search, NSGA-II search, original genotype fitness, crossover, mutation or FIFO runtime.
- Fixed 3 familiar DAX family instances `CyberShake_50`, `Sipht_60`, `Epigenomics_100`, new original seeds **903/904** (previous stage experiment 801/802 and evolutionary K16 901/902). These are NOT new workflow-family holdouts. Original VM profile default, 16 VMs, original STATIC FIFO, 30 population/100 generations = exactly **3030 search evaluations per solver**. Both solvers: `DAG-Pareto-FLA[v12-hvbandit]`, `NSGA-II[costseed]`.
- After search, deterministic `budgetedPlannedCoverage` selects N32 physical maps from all visited genotypes BEFORE any true simulator replay. Exact ordered physical genotype map fingerprint must match across all four selector variants within each DAG/seed/solver.
- OLD greedy calls OLD 32× and READY 0×; READY greedy OLD 32× READY 32×; STAGED T8 OLD 32× READY 8×; ACTIVE T8 OLD 32× READY 8×. These are **post-search** decoder calls additional to the 3030 original optimizer fitness visits. No CPU equalization is implied.
- K8 physically distinct selected maps, exact original assignment replay in WorkflowSim, shared actual HV reference (1.5x all eight solver×mode K8 sets) within each DAG/seed, sensitivity 3.0x. All adverse, tied, favorable blocks preserved.
- 3 DAX ×2 seeds ×4 selector variants =24 GitHub Actions source jobs, 2 solvers each, K8 each = **384 real simulator replays if completed**.
- Required full-source checks: 3030 original objective evaluations each, 8 physical K replays each, exact (OLD,READY) post-search decoder count, shared pool fingerprints, same initial two seeds, finite actual objective pairs, identical frozen source commit across arms. Original frozen selections are not retrospectively re-executed with altered parameters.
- Primary paired comparisons: ACTIVE vs STAGED with equal READY T8; ACTIVE vs OLD (quality value of extra READY); ACTIVE vs FULL READY (cost-quality frontier). Secondary compute: READY model call reduction and selector elapsed time, **not** overall speedup inferred from model call count.
- Clear rejection criteria: negative mean vs OLD or STAGED, systematic family regressions, failure of shared source/pool identity, or fabricated/missing actual simulator outputs. Treat two seeds from one DAG family as correlated; no publication significance or generalization from three familiar families.
- This entire new policy must remain **opt-in**, with `master` and previous `staged-greedy` semantics unchanged.
