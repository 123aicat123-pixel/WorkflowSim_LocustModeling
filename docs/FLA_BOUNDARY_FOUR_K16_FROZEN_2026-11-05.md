# Frozen prospective K16 boundary-risk rescue versus matched random exploration (2026-11-05)

**Preregistered BEFORE implementation is executed on new true WorkflowSim labels.** This study tests a cheap planned-objective candidate REPLAY selector, not a novel FLA optimizer or calibrated dominance guarantee. Previous v20 K16 data (seeds 951,952) are development evidence and **must not be reused as test outcomes**.

## Hypothesis
The matched-optimizer K16 planned-Pareto vs random K16 experiments found 45/939 false planned-dominance orientations and 14 random-only retrospectively useful candidates, but almost no FLA-v12 observable union-HV headroom. Therefore blindly reserving K slots for nearby planned-dominated candidates may be wasteful. A falsifiable new comparison tests whether deterministic proximity-to-selected-front risk ranking outperforms both (a) an all-16 planned Pareto-cover baseline and (b) equal K12+4 *stratified-random dominated-candidate* exploration.

## Fixed methods, full budget accounting
- Two identical **original optimizers**, `DAG-Pareto-FLA[v12-hvbandit]` and cost-seeded `NSGA-II[costseed]`, 30 population, 100 generations, 3030 original target fitness visits per solver; original FIFO STATIC WorkflowSim replay and default VM speed profile. No changes to original optimizer, FLA operators or search target objectives. Original search-history SHA must match across all three replay policies per DAG/seed/solver.
- Three fixed selection arms, each **exactly K16 actual simulator calls per solver**:
  1. `pareto-cover`: original 16-item planned Pareto-peeling/max-min-coverage selector.
  2. `boundary-four`: exact first K12 from unchanged `pareto-cover`; among visited unique genotypes not selected, retain those strictly PLANNED-dominated by at least one K12 member, order them by planned makespan, form **four equal-count quantile strata**, and take one per stratum minimizing the smallest normalized positive max-axis domination margin to its K12 dominator (canonical tie break). No true labels or READY oracle.
  3. `dominated-random-four`: **same exact first K12**, same full eligible planning-dominated candidate set and four strata, one uniform seeded random candidate per stratum. Separate fixed deterministic sampling salt; this ablates proximity ranking rather than just the K12+4 exchange.
- No tuning of K12, four strata, dominance margin, or seeds after observing outcomes; no secondary screening or feedback. Fail if there are fewer than 4 eligible planned-dominated distinct mappings. No planned-NULL fallback that changes the trial.
- New **instance/scale combinations** compared to the previous v20 951/952 study: `Montage_50`, `Inspiral_50`, `CyberShake_30`, `Epigenomics_46`, new seeds **971,972**. These four DAG families have been previously studied in other repository work: this is **not an unseen-family generalization claim**, even though the exact selected instance sizes/seeds differ from prior v20 trials.
- Design: 4 workflows × 2 seeds × 3 replay selectors = **24 source jobs**, each of the 2 original solvers carries 3030 counted search visits and 16 actual WorkflowSim replays: planned **768 real K16 simulator replay observations** (some physical assignments may repeat across selectors and are not independent). Source commit SHA, exact search fingerprints, first 12 physical mappings for matched K12+4, the extra 4 eligible maps, wall/selection/simulation times are archived.
- Report actual two-objective Makespan/Cost HV with one common 1.5x ACTUAL reference shared by both solvers and all 3 selection policies within each workflow/seed, with 3x sensitivity. Fixed K16 is a replacement budget; **do not** compute the optimistic K12+4+baseline union and call it feasible K16. Report wins/ties/losses per original workflow/seed/solver and cost/quality tradeoff, no pseudoreplication from 16 replays.
- Primary tests: `boundary-four - pareto-cover`, and critically `boundary-four - dominated-random-four`. Secondary: distinct selected-mapping overlap and frequency of planning-dominated candidates that become truly nondominated among the 16 selected. Qualitative failure on either key comparison rejects promotion; no significance claims from only 8 DAG/seed blocks.

## Scientific limitations / stop rules
A planning-dominance margin is a heuristic and **not** a predictive uncertainty interval. The outcome can be negative: previously tested static epsilon Pareto tolerances, model residual correction and v20 Hamming novelty also failed. Do not tune the boundary rule after new outcomes and reuse the same labels as an independent validation. No equal total CPU budget claim follows from 3030 original fitness visits; profile the actual selection + search + replay overhead.

This only tests post-search simulator selection, not an improvement to FLA's evolutionary search or a proven Pareto guarantee. The required next gate for a publishing claim is independent held-out family and/or simulator regime, at least 20 independent seeds per block, stronger external baselines, and controlled equal measured compute. All changes opt-in on `fla-baseline`; `master` stays untouched.
