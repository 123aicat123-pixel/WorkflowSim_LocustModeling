# Prospective research gate: calibrated two-fidelity FLA (design only; not a result)

Date: 2026-11-04. Branch: `fla-baseline`. This document is a **new protocol proposal**, not an executed benchmark or proof of calibration. Do not retroactively treat previous 96 mappings or the CyberShake/Sipht optimizer outcomes as an untouched holdout.

## Motivation and negative evidence
- Source: `docs/FLA_INTERVAL_DOMINANCE_AND_FAMILY_BLOCKED_ACTUAL_RESULTS_2026-11-04.md`. Leave-one-family-out empirical max residual intervals jointly covered **89/96** for each OLD and READY predictor; these observed failures explicitly refute a transferable worst-case guarantee.
- Source: `docs/FLA_EVOLUTION_FIDELITY_CACHE_MATCHED_ACTUAL_RESULTS_2026-11-04.md`. PERIODIC/RISK inside evolution have inconsistent true K8 HV wins/losses; 1% RISK used almost all its READY quota. Neither is an established algorithmic improvement.
- Source: `tests/org/workflowsim/planning/IntervalParetoCertificatePropertyTest.java`. Geometric correctness **conditional on actual coverage** does not imply generalization, confidence, or safely calibrated intervals.

## Explicit go/no-go gates (in order)
1. **Source/CI gate**: compile all Java sources and run existing schedule/decode/interval tests plus the deterministic interval property oracle. Capture git SHA, exact tests, Actions URL, logs, and failure traces. A missing run/status is UNKNOWN, not PASS.
2. **Independent data gate**: select and lock a DAG family not used in parameter fitting or threshold selection **after auditing all prior datasets**. Freeze workflow instance files, SHA256, VM configurations, seed list, simulation runtime and train/calibration/holdout partition BEFORE observing target-family truth. Do not reuse known CyberShake, Sipht, Montage, Epigenomics as an allegedly untouched family.
3. **Coverage/calibration gate**: use cross-family calibration (not raw maximum-error transfer as a guarantee). Specify intended joint miscoverage alpha *a priori*, one family as one independent unit, coordinatewise score definition and joint-event aggregation, handling of distribution shift and an abstain/READY fallback. A distribution-free new-family guarantee is **not justified** by three correlated training families. Report per-family empirical coverage and failures with Wilson intervals only where independence assumptions are defensible. No coverage claim if data do not permit reliable calibration.
4. **Policy correctness gate**: throughout evolution, operate on a common comparable objective representation. The strict interval comparator can certify a pair only when both error boxes are valid; otherwise **abstain** and optionally spend a counted READY call. Never simply mix uncalibrated OLD/READY scores and treat their Pareto relations as exact. Cache maps by canonical TaskID->VM assignment; count every cheap/ready physical call and cache hit, including duplicate visits.
5. **Fair optimizer gate**: compare FLA-v12 OLD-cached, FLA FULL READY-cached, FLA PERIODIC-cached, experimental FLA gated, and the corresponding seeded NSGA-II controls; prespecify initialization and genotype visit budget, VM and billing conditions, random seeds, final replay selection policy, and **K16 actual WorkflowSim replays per optimizer arm**. All arms receive both matched genotype visit budget and a second wall-clock/CPU-time matched experiment. Report whole-run elapsed time and model-only times separately.
6. **Primary metric**: paired true WorkflowSim normalized 2-D hypervolume with a common reference within each exact workflow/seed block; preserve source actual Makespan/Cost, selected candidate hashes, and 3x reference sensitivity. Secondary IGD+ requires an explicitly described common empirical reference front; never call this the unknown theoretical Pareto front.
7. **Statistical decision**: evaluate family-stratified paired differences with confidence intervals and complete win/tie/loss tables, not independent-task pseudo-replicates. Include negative instances and reference sensitivity. Claim general improvement **only** if held-out family evidence is repeatable and favorable under compute-time matching and the precommitted reference and metric; otherwise report engineering feasibility or failure only.

## Implementation separation
- Existing `IntervalParetoCertificate` remains an opt-in **pure mathematical primitive**. It must not be activated as a default scheduler pruning rule without an independently validated interval source and explicit fallback.
- Any new evolution policy gets its own opt-in mode; old FLA, NSGA-II, stage-in and FIFO defaults remain untouched. Keep scripts, raw data, exact CI provenance, and all failures in `fla-baseline`; do not merge to `master`.
- A design/commit is not an executed experiment. No claim of SCI/Q1 readiness follows from passing CI, sampling 20,000 toy boxes, or achieving coverage within the development data.

**Status as of protocol authoring:** blocked at verifiable new CI results and a genuinely independent held-out-family design; no algorithmic superiority claim.
